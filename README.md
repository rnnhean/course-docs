# 课程文档

从 B 站课程整理的中文技术文档。每门课一个目录，文档和它引用的截图放在一起，克隆下来直接打开就能读。

## 结构

```
.
├── INDEX.md                    全部课程索引
├── 00-BV1iTn262EUh-DeepSeek-Harness/
│   ├── BV1iTn262EUh-p1-14.doc.md
│   └── images/                 该文档引用的截图
├── 02-BV1jcRKBEEfK-Docker-Masterclass/
└── ...
```

文档里的图片用相对路径 `images/xxx.jpg`，本地用任何 Markdown 阅读器打开、或在 GitHub 网页上看，都能直接显示。

## 文档怎么写的

每份文档按同一套结构：

1. **这一节做什么** —— 这段课要解决什么问题
2. **讲师原话** —— 带 `pNNN [MM:SS]` 出处，中文译文
3. **从零复现** —— 按依赖顺序的步骤
4. **完整代码** —— 配置与代码，课程没念出的字段会标注
5. **逐行解释** —— 每个设计为什么这么做
6. **复现检查清单** —— 按顺序打勾
7. **课里没讲但你会撞上的** —— 坑与补法
