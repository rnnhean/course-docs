[06:00] Governance for Multi-Agent Systems Multi-Agent Systems introduce a class of failure modes that single-agent systems do not have. The most concerning is Agent Collusion, a setup where multiple agents reinforce each other's wrong answers because they share assumptions, biases, or training data, and no external check breaks the loop. A grounding agent that uses the same model as the agent it is grounding will tend to validate the same hallucinations the original agent produced.
[06:29] Several practices reduce collusion risk, use different models for evaluator agents than for the agents being evaluated, because models from different providers tend to fail in different directions, and an evaluator with the same training data shares the same blind spots. Where different models are not practical, use different prompts and personas to push the evaluator toward a different stance. An evaluator prompted to find problems behaves differently than one prompted to confirm correctness, even on the same model.
[06:58] Periodically include human review on flagged outputs and on a random sample of unflagged outputs because an automated evaluation system that is never checked against ground truth can drift undetected. Governance beyond collusion includes a few standard moves worth naming. Define a clear authority hierarchy, which agent has the final say when evaluators disagree. Log every agent to agent message so disagreements and decisions are auditable after the fact.
[07:26] Set escalation rules for cases where evaluators cannot agree or where confidence drops below a threshold with human review as the fallback. Limit each agent's authority to what its role requires, so a single compromised or malfunctioning agent cannot cascade decisions across the system. These practices are not unique to evaluation agents, but they show up most acutely there because evaluation is where the system's measure of its own correctness lives.
[07:54] An evaluation layer that colludes with the agents it is evaluating is worse than no evaluation layer because it provides false confidence. Treating governance as part of the evaluation design, not as a separate concern bolted on later, is the durable framing.
