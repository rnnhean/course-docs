[04:07] Each tool you register with an agent adds instructions to the prompt describing how to use the tool. More instructions and longer prompts increase variability and the potential for failures in the system. Tools can fail. Each tool adds another potential point of failure and another surface area where the agent may need to recover. Robust, agentic workflows minimize points of failure and plan for the failures that do happen. The common patterns are retries with back off for transient failures, network timeouts.
[04:37] Rate limits, structured error returns the agent can read and respond to, rather than raw exceptions that crash the loop. Fallback tools are alternate paths when a primary tool is unavailable, and time out so a hanging tool does not stall the agent indefinitely. Tools are decisions. [05:06] may not be wise. Be cognizant of the decisions you empower your agents to make and be comfortable with the results if they make the wrong ones. If you allow an agent to delete files, expect it to delete all the files it has access to. Tools are potent additions to agents, but they provide many opportunities for misuse and points of failure.
