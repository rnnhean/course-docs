Section 10.1.3 Defining Cognition for Agents Before we build anything, we need to be precise about what we mean by cognition in the context of agent systems. We are not making philosophical claims about machine consciousness. We are defining observable capabilities that we can engineer and measure.
[09:53] Agent cognition is the quality of the agent's internal model of a task. A cognitive agent does not just process a query and produce a response. It builds a representation of what is being asked, reasons about how to approach it, and updates that representation as new information arrives. Four capabilities define cognitive agents. Task decomposition is the ability to break a novel problem into subtasks without being shown how. This goes beyond following a template.
[10:22] A cognitive agent encounters a problem it has not seen before and figures out what steps are needed. Dependency reasoning is the ability to identify which subtasks depend on others and sequence them correctly. It is not enough to decompose a problem into three parts. The agent needs to know that Part B requires the output of Part A and that Part C can run in parallel. Compositional tool use is the ability to combine tools in configurations the agent was never explicitly shown.
[10:52] The agent has a search tool and a comparison tool. Nobody told it to chain them together for cross-referencing queries. A cognitive agent figures that out from the problem structure. Model updating is the ability to revise understanding as new information arrives. The agent starts with a hypothesis about what the user needs. Midway through execution, new evidence contradicts that hypothesis. A cognitive agent updates its plan. A non-cognitive agent plows ahead.

Section 10.1.4, Defining Metacognition for Agents.
[11:47] If cognition is the quality of the agent's thinking, metacognition is the agent's ability to think about its own thinking. This is not a philosophical nicety. It is the most practically important capability for production agent systems. Metacognition for agents means three things. Confidence calibration is the extent to which an agent's expressed confidence correlates with correctness. It is not whether the agent says, I'm not sure, which language models can be prompted to say about anything.
[12:16] Real confidence calibration means that the agent's internal signals, token probabilities, retrieval scores, and evidence consistency predict whether the output is correct or incorrect. Research from Wang et al. 2025 in the DMC framework showed that implicit confidence measures derived from token likelihoods are better predictors of correctness than verbal expressions of confidence. This is the gap we will exploit architecturally.
[12:44] Stagnation detection is the agent's ability to recognize when it is not making progress. A non-metacognitive agent will retry the same failing approach until it hits an iteration limit. A metacognitive agent notices after two iterations that its findings are not changing and pivots to a different strategy. Knowledge boundary awareness is the extent to which an agent's behavior changes when it operates outside its knowledge. The Metamed QA benchmark, Nature Communications 2025,
[13:14] tested this directly and found that models consistently provided confident answers even when the correct option was absent from the choices. The models could not tell when they did not know. Building knowledge boundary awareness into the architecture is how we fix this. The implicit-explicit confidence gap. Research shows that LLM's internal uncertainty signals, token entropy, log-prop distributions,
[13:40] predict correctness better than their verbal expressions of confidence. An agent saying I'm confident tells you almost nothing, but an agent whose token probabilities are high across its answer tokens is genuinely more likely to be correct. Minsky's Society of Mind Marvin Minsky argued that the mind is not a single intelligent process but a society of specialized agents. None of these agents is intelligent on its own, but their interactions produce intelligent behavior. No single neuron understands language.
[15:34] No single brain region solves math. Intelligence emerges from the interaction of many simple specialized components. For agent architecture, the implication is clear. Stop trying to build a single smart agent. Build multiple specialized agent modules, one that understands the problem, one that plans, one that executes, and one that evaluates. Then let intelligence emerge from their interaction.
[16:00] This is not the same as a multi-agent system where agents pass messages. It is a tighter integration in which agent modules share state and influence one another through a common medium. Bernard Barr's proposed that consciousness works like a theater. Specialized neural processes operate backstage, each doing its own thing. But there is a single stage, the global workspace, where the most important signal at any given moment is broadcast to all other processes.
[16:30] This broadcast is what we experience as conscious attention. For agent architecture, this gives us the cognitive workspace a shared state object that all agent modules read from and write to. The workspace is not a message queue. It is a living representation of the agent's current cognitive state, what it knows, what it is trying to do, how confident it is, and what signals need attention. When the evaluation module writes contradiction detected to the workspace,
[16:58] Every other module can see it. Kahneman's System 1 and System 2. Daniel Kahneman's framework describes two modes of thinking. System 1 is fast, automatic, and effortless. You recognize a face or read a word without trying. System 2 is slow, deliberate, and effortful. You solve a math problem or plan a vacation by thinking carefully. For agent architecture, this means not every query deserves the full cognitive treatment.
[17:25] A simple factual lookup should bypass planning and evaluation entirely, going straight from perception to execution to response. A complex, ambiguous, or contradictory query should trigger the full cognitive cycle with planning, evaluation, and potential replanning. The attention module implements this routing. This is as much an efficiency argument as a capability argument. Unnecessary reasoning burns tokens, adds latency,
