There are several types of NoSQL databases, including the following. Document Store

Key value store, stores data as key value pairs, similar to a dictionary, for example, Redis and DynamoDB. [00:58] Organizes data into columns and rows, but unlike in relational databases, columns can vary between rows, for example Cassandra and HBase. The world of no SQL has no common database type or standard. The term merely means a data storage technology that doesn't rely primarily on SQL. Even different databases in the same category work differently.
[01:22] Various NoSQL technologies exist because traditional relational databases aren't always the best solution for certain problems. A key value store, for example, is the best database choice for a distributed cache because quick data retrieval is the most important feature. Column family databases are much better suited to data warehousing, which stores large volumes of data. Graph databases are best for building complex connection maps
