[00:00] Section 7.3 Overview of Distributed Cache and Lock Distributed caching is a mechanism for storing frequently accessed data in a shared high-performance data store that spans multiple servers or nodes. This type of caching is typically used to improve application performance and scalability in distributed systems. When we use a cache, we store data in random access memory, RAM, rather than on a disk, unless the cache is a special purpose on-disk cache.
[00:29] Reading data from RAM is much faster than interacting with storage disks, so caches can improve application performance significantly, especially when the cache is hit often. This is especially important when we're dealing with large volumes of data. When we use a tool like Redis, the same cache can be shared among separate applications and even separate physical machines. If one application populates the cache, other applications can access it too. This is why such a cache is called distributed.
